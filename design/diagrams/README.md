# Ember & Iron diagrams - v1.1

Current reference diagrams: game-flow.svg, item-tree.svg, room-trees.svg, legacy-tree.svg, ui-layout.svg and ui-mobile.svg.

Run `python design/diagrams/current_diagrams.py` to regenerate current dashboard diagrams. The full specification embeds the SVG files directly. Legacy depth costs are 2, 4, 7, 11, 19 and 33 sparks.

Earlier scene-layout generators and living-village.svg remain historical design references; they do not describe the current UI. Their old aggregate build command should not be used to replace current dashboards.
